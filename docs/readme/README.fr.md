# HopTubePlay

[🌐 Languages / Langues](../../README.md)

**v1.0.0** — overlay now playing YouTube pour OBS, Streamlabs et les autres sources navigateur.

**Par [GalaxyBunny Studio](https://github.com/HanaCherry)**

C’est un **lecteur de clip**, pas un lecteur audio. Lance une vidéo YouTube dans Chrome ou Edge, choisis un skin, copie l’URL dans OBS.

## Fonctionnalités

- 56 skins (Cinéma, Galaxy Bunny, kawaii, film, VHS, sakura, et plus)
- Clip YouTube muet dans les lecteurs vidéo, miniature en secours
- Détection Windows automatique
- Couleurs magiques, lueur, flou, visualiseur
- 9 positions d’overlay
- Jusqu’à 5 profils
- Mode démo local

## Lancer

```bash
npm install
npm start
```

Ouvre http://127.0.0.1:3001
