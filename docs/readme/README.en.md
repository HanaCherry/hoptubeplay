# HopTubePlay

[🌐 Languages / Langues](../../README.md)

**v1.0.0** — YouTube now-playing overlay for OBS, Streamlabs, and other browser sources.

**By [GalaxyBunny Studio](https://github.com/HanaCherry)**

This is a **clip player**, not an audio-only overlay. Play a YouTube video in Chrome or Edge, pick a skin, copy the overlay URL into OBS.

## Features

- 56 skins (Cinema, Galaxy Bunny, kawaii, film, VHS, sakura, and more)
- Muted YouTube clip in video players, thumbnail as fallback
- Automatic Windows detection
- Magic colors, glow, blur, visualizer
- 9 overlay positions
- Up to 5 profiles
- Local demo mode

## Run

```bash
npm install
npm start
```

Open http://127.0.0.1:3001
