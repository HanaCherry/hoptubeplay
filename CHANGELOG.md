# Changelog

## 1.0.0

- First public release of HopTubePlay
- YouTube now-playing overlay for OBS / Streamlabs
- Windows auto-detect (Chrome, Edge, YouTube, YouTube Music)
- Video skins play a muted YouTube clip; thumbnail stays underneath
- Music skins use the thumbnail
- 56 player skins including Cinema and Galaxy Bunny
- Local demo mode
- Optional Pear Desktop (Amuse / API Server) for advanced setups
- Dashboard UI in 30 languages
- Private by design: `127.0.0.1` only, `data/` never published
